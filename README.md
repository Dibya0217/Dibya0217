## `featured_projects`

### Logistics Platform

Production-grade logistics and shipment backend built as a set of independently deployable services.

`Java` `Spring Boot` `Microservices` `Kafka` `PostgreSQL` `Redis` `Spring Security` `Docker`

- Microservices split by domain (auth, order, shipment, tracking, notification)
- Asynchronous inter-service communication over Kafka topics
- Role-based access control with Spring Security
- Redis caching on read-heavy tracking endpoints
- Fully containerised with Docker Compose

[**View project →**](https://github.com/Dibya0217/logistics-platform)

---

### Banking Platform

Enterprise banking backend covering account management and transaction processing.

`Java` `Spring Boot` `Microservices` `Kafka` `PostgreSQL` `Redis` `JWT` `Docker`

- Stateless JWT authentication across services
- Transaction processing with Kafka-based event publishing
- Secured REST APIs with request validation and error handling
- PostgreSQL persistence, Redis for session and lookup caching

[**View project →**](https://github.com/Dibya0217/banking-platform)

---

### KnowledgeHub AI

AI-powered enterprise knowledge assistant using retrieval-augmented generation.

`Java 25` `Spring Boot` `Spring AI` `Qdrant` `PostgreSQL` `React` `Docker`

- Document ingestion, chunking, and embedding pipeline
- Vector similarity search backed by Qdrant
- RAG-based question answering via Spring AI
- React frontend, Dockerised end to end

[**View project →**](https://github.com/Dibya0217/knowledgehub-ai)

---

### WhatsApp Clone

Real-time messaging application with an event-driven backend.

`Spring Boot` `Kafka` `MongoDB` `React` `JWT`

- Real-time message delivery through Kafka topics
- JWT-secured REST APIs
- MongoDB persistence for chats and message history
- React client

[**View project →**](https://github.com/Dibya0217/whatsapp-clone)
